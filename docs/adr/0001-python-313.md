# 0001. Python 3.13 as the development baseline

## Status

Accepted

## Context

The SDK needs a minimum supported Python version. LogRhythm's REST APIs impose no
constraint on this choice, so the decision is driven by the SDK's own goals: modern,
stable typing features, a long support runway, and a clean starting point for a new
project with no legacy consumers to support.

## Decision

The SDK targets Python 3.13 or newer as its minimum supported version. Development
tooling (Ruff, mypy) is configured against this same target. Modern, stable Python
syntax is used where it improves clarity; unnecessarily experimental or unstable
language features are avoided.

## Consequences

- Users on Python versions older than 3.13 cannot install the SDK. Given this is a new
  project, this has no migration cost for existing users.
- The SDK can rely on current typing syntax and standard-library behavior without
  backward-compatibility shims.
- Raising the minimum version later remains possible but is a breaking change and
  should be recorded in its own ADR if it happens.
